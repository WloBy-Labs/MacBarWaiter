# MacBarWaiter 1.0.0

第一个正式分发的版本。

菜单栏状态项排不下时 macOS 会直接不渲染它们 —— 图标依然占着坐标和宽度，只是画不出来，
而且丢哪些不由你定。有刘海的机器尤其严重。MacBarWaiter 在菜单栏放一个下拉按钮，
点开就把**所有**状态项原样列出来，包括那些完全看不见的；当前不可见的那几个底下画一道横线标出。

## 相比 0.1.0

- **Release 包改用稳定的自签身份签名**（`MacBarWaiter CI Signing`）。
  0.1.0 是 ad-hoc 签名，每次更新签名都变，macOS 会当成另一个 App 从而要求重新授予
  屏幕录制权限。换成固定身份后，以后更新不再需要重新授权
- 功能与 0.1.0 一致

> 从 0.1.0 升上来的话，需要再授权一次屏幕录制（这是最后一次）—— 签名身份变了。

## 安装

打开 DMG，把 MacBarWaiter 拖进 Applications。

首次运行需要在「系统设置 → 隐私与安全性 → 录屏与系统录音」里授予**屏幕录制**权限，
然后重启 App（这个权限要重启进程才生效）。抓取菜单栏图标的像素必须要这个权限，绕不过去。

证书是自签的、未经 Apple 公证，所以首次打开 Gatekeeper 会警告，
需要在「隐私与安全性」里点一次「仍要打开」。

## 已知限制

- **只能看，不能点**：面板里是抓下来的图，点不了
- **标不出名字**：现代 macOS 上状态项统一由 Control Center 托管，
  拿不到图标真正归属的 App
- 下拉按钮自己也要占菜单栏一格；别 ⌘ 拖动把它挪到看不见的位置
