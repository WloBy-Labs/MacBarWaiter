# MacBarWaiter 0.1.0

第一版。菜单栏放一个下拉按钮，点开列出**全部**状态项 —— 包括被 macOS 挤掉、
完全画不出来的那些。当前不可见的图标底下会画一道横线标出来。

- 用 ScreenCaptureKit 按窗口 ID 逐个抓图，离屏的状态项也抓得到
- 内容超过面板宽度自动换行；单个超宽项（如 319pt 的「正在播放」歌名）独占一行而不被丢弃
- 面板底色按抓到的图标平均亮度自动选深或浅，保证跟白字/黑字都有反差
- 缺屏幕录制权限时给出明确提示和一键跳转设置
- 多屏：只列出下拉按钮所在那块屏的菜单栏
- 以拖拽安装的 DMG 分发，附 Applications 快捷方式
- 渐进式签名：默认 ad-hoc，配置了证书就用稳定身份，提供 Apple 凭据则额外公证。
  用稳定身份签名可以在更新之间保住「屏幕录制」权限
